# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2024-01-XX

### Added
- Initial release of Dorisio SDK
- Core wallet functionality for Stellar networks
- Payment processing capabilities
- Transaction signing and verification
- Support for testnet and mainnet environments
- TypeScript type definitions for all public APIs
- Comprehensive API documentation

### Security
- Secure key storage patterns and recommendations
- Built-in validation for transaction amounts
- Support for multi-signature transactions

### Documentation
- Complete API reference
- Integration guides
- Security best practices
- Code examples
